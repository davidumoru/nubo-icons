Nubo is young. This page covers what's ready, what's being worked on, and what might come later. Need something sooner? [Open an issue](https://github.com/davidumoru/nubo-icons/issues/new) and say what it's for.

## Ready

- **186 icons**, each in Line, Fill and Duo.
- **This site**: search, a preview of every icon, SVG and React code, and downloads as SVG, PNG or a zip of the whole set.
- **`@nubo-icons/react`** on [npm](https://www.npmjs.com/package/@nubo-icons/react), with a [changelog](/docs/changelog) for every release.

## Next

1. **More icons**, added in reviewed batches. [Requests](https://github.com/davidumoru/nubo-icons/issues/new) decide what comes first.
2. **`@nubo-icons/svg`**: optimized SVG files and icon data as JSON, for any framework or build tool.
3. **Iconify.** Getting listed there brings support for Tailwind, UnoCSS and unplugin-icons.

## Later

Ideas, not promises.

- **Morphing icons**: a component that animates between related icons, like menu to close or play to pause.
- **More weights**: a bold version, and thin and light ones.
- **Vue and Svelte** packages.
- **A Figma library.**
- **An MCP server**, so AI coding tools can find and insert icons.
